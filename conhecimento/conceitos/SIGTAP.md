# SIGTAP

**Em uma frase.** A tabela de procedimentos do [[SUS]]: código, nome, valor e as exigências
de cada procedimento.

- Cada procedimento tem uma [[Ficha do SIGTAP]] por [[Competência]].
- O código tem cinco partes: [[Código SIGTAP]].
- Muda por portaria a cada poucos meses; o valor que vale é o da competência vigente.
- No DF, o preço é a [[Tabela SUS Candanga]] quando o código está no Anexo e o valor dela é maior.
- Quem lê é o agente `ficha-sigtap`.
