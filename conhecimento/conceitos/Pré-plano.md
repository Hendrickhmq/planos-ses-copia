# Pré-plano

**Em uma frase.** O "Plano de Trabalho Simplificado" que a [[ARINS]] pede por ofício: serve
para a [[SES-DF]] decidir se e como fazer.

- Todo número escrito vira compromisso: o [[Plano de trabalho]] é conferido contra ele.
- Nove campos, na ordem do formulário; só o custo assistencial.
- O campo do [[Enquadramento jurídico]] é da [[SUCONV]], literal.
- Versão geral ou de item único; carteira com reserva.
- Exemplo: [[redacao_05 - OCI de otorrino]].
